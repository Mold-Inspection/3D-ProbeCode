# ขั้นตอนตรวจจุดคาดหวังเทียบกับ CAD ใน SolidWorks (ทีละคลิก)

**เป้าหมาย:** พิสูจน์ว่าจุดคาดหวังที่โปรแกรม 3D ProbeCode วาง **อยู่บนผิว CAD จริง** โดยใช้ SolidWorks
วัดเส้นผ่านศูนย์กลางของหน้าตัดรูที่ความลึกเดียวกับแต่ละชั้น แล้วเทียบกับ ⌀ ของวงจุดคาดหวัง
ใช้กับหัวข้อ 3.8 และ 4.1 ของเปเปอร์ (ตารางที่ 1)

ชิ้นงาน: `taper test .STEP` (รูกรวย 15° ปาก ⌀22 ลึก 20) และ `test 2 shpere.STEP` (หลุมทรงกลม R10)

---

## ก. ค่าที่ต้องเทียบ (ฝั่งโปรแกรม)

ร่างเปเปอร์ตอนนี้ใช้ค่าที่ Claude ดึงจากโปรแกรมด้วยสคริปต์ (3 ชั้น ชั้นละ 4 จุด ลูกบอล ⌀2):

| ชิ้นงาน | ชั้น | ความลึกจากปากรู (มม.) | ⌀ จุดคาดหวัง (มม.) | ⌀ SolidWorks (มม.) | ผลต่าง |
|---|---|---|---|---|---|
| Taper 15° | 1 | 5.000 | 19.3205 | 19.3205 | < 0.0001 |
| Taper 15° | 2 | 10.000 | 16.6410 | 16.6410 | < 0.0001 |
| Taper 15° | 3 | 15.000 | 13.9615 | 13.9615 | < 0.0001 |
| Sphere R10 | 1 | 2.500 | 19.3649 | 19.3649 | < 0.0001 |
| Sphere R10 | 2 | 5.000 | 17.3205 | 17.3205 | < 0.0001 |
| Sphere R10 | 3 | 7.500 | 13.2288 | 13.2288 | < 0.0001 |

ค่า ⌀ SolidWorks ข้างบนได้จากสคริปต์ (6 พ.ย. 2569, SOLIDWORKS 2021 SP3.0): ทำตามขั้น ข.–จ. ผ่าน API
ผลต่างสูงสุดที่ความละเอียดเต็มคือ 0.0000026 มม. (หลุมทรงกลม ชั้น 3)
ไฟล์ผลอยู่ใน `Desktop\Project\SolidWorks_check\` (`*_check.SLDPRT`, ภาพ `*_iso/front/top.jpg`, `sw_results.json`)
รอบถัดไปให้วัดเองตามขั้นตอนข้างล่าง แล้วเทียบกับค่าชุดนี้

ตรวจทานด้วยมือได้: taper ⌀ = 22 − 2·d·tan 15° · sphere ⌀ = 2·√(10² − d²)

**ครั้งถัดไป (อ่านค่าเองจากโปรแกรม):**
1. เปิดไฟล์ STEP ในโปรแกรม เลือกรู ตั้ง 3 ชั้น 4 จุด/ชั้น, Hardware Setting ลูกบอล ⌀2
2. Hardware Setting: Work zero = **Center of object** (Z0 อยู่ที่ผิวบนเสมอ)
   และ Z0 reference = **Ball centre at the top surface** → Export G-code
   โปรแกรมบันทึกไฟล์ `..._schema.json` คู่กับ G-code
3. เปิดไฟล์ `.json` ด้วย Notepad ในส่วน `"points"` เลือกจุดใดก็ได้ของแต่ละ `layer_idx` (0, 1, 2)
   อ่านค่า `x`, `y`, `z`
4. ⌀ จุดคาดหวัง = 2 × √(x² + y²) · ความลึกจากปากรู = −z
   - ถ้าใช้ค่าเริ่มต้น *Ball bottom touches the top surface* โปรแกรมเลื่อน Z ทุกจุดลงเท่ารัศมีลูกบอล
     → ความลึก = −z − 1 (ลูกบอล ⌀2) ส่วน ⌀ ไม่เปลี่ยน
5. ถ้าความลึกต่างจากตารางข้างบน ให้ใช้ความลึกของตัวเองในขั้นตอน ค.

## ข. เตรียมไฟล์ใน SolidWorks

1. **File → Open** → ช่อง *Files of type* เลือก **STEP AP203/214/242 (\*.step; \*.stp)** → เลือก `taper test .STEP` → **Open**
   - ถ้าถาม *Run Import Diagnostics?* → **No**
   - ถ้าถามแม่แบบ (template) → เลือก **Part** หน่วย mm
2. ตั้งทศนิยม 4 ตำแหน่ง: **Tools → Options → แท็บ Document Properties → Units**
   → เลือก **MMGS** → แถว *Length* ช่อง *Decimals* เลือก **.1234** → **OK**
3. ตรวจตำแหน่งผิวบน (ปากรู): ใน FeatureManager (ต้นไม้ด้านซ้าย) คลิกขวา **Top Plane → Show**
   → **Tools → Evaluate → Measure** → คลิกผิวบนของชิ้นงาน แล้วคลิก Top Plane
   → ควรได้ *Normal Distance* = **25.0000** มม. (แกนรูขนานแกน Y) — จดค่าไว้ ปิดหน้าต่าง Measure

## ค. สร้างระนาบตัด 3 ชั้น

4. **Insert → Reference Geometry → Plane**
   - *First Reference*: คลิก **ผิวบนของชิ้นงาน** (ผิวที่มีปากรู)
   - ช่อง *Offset distance*: พิมพ์ **5.000** mm
   - ถ้าระนาบตัวอย่าง (สีเหลือง) อยู่เหนือชิ้นงาน ให้ติ๊ก **Flip offset** ให้ระนาบลงไปในเนื้อ
   - คลิก ✔ (OK)
5. ในต้นไม้ คลิกช้า ๆ สองครั้งที่ *Plane1* → ตั้งชื่อ **L1_5mm**
6. ทำซ้ำข้อ 4–5 สำหรับความลึก **10.000** (L2_10mm) และ **15.000** (L3_15mm)
   - หลุมทรงกลมใช้ **2.500 / 5.000 / 7.500**

## ง. วัดเส้นผ่านศูนย์กลางที่แต่ละระนาบ

7. คลิกระนาบ **L1** ในต้นไม้ → แท็บ **Sketch** → **Sketch** (เปิดสเก็ตช์บนระนาบนี้)
8. **Tools → Sketch Tools → Intersection Curve** (หรือปุ่ม *Intersection Curve* ในแท็บ Sketch)
   → คลิก **ผิวผนังรู** (รูกรวย = ผิวกรวย, หลุม = ผิวทรงกลม — ถ้าผนังแบ่งเป็นสองซีก คลิกทั้งสองซีก)
   → คลิก ✔ จะได้วงกลม (หรือส่วนโค้งสองชิ้น) บนระนาบ
9. **Smart Dimension** → คลิกวงกลม/ส่วนโค้ง → เลื่อนเมาส์ให้แสดงเป็น **⌀** แล้ววางตัวเลข
   - ถ้าถาม *Make this dimension driven?* → เลือก **Make this dimension driven** → OK
   - หรือใช้ **Tools → Evaluate → Measure** คลิกวงกลม จะแสดง *Diameter*
10. ออกจากสเก็ตช์ (มุมขวาบน ไอคอนออกจาก Sketch) → ตั้งชื่อสเก็ตช์ **L1_dia**
11. ทำซ้ำข้อ 7–10 กับระนาบ L2 และ L3
12. จดค่า ⌀ ลงตาราง ก. และคำนวณ **ผลต่าง = ⌀ SolidWorks − ⌀ จุดคาดหวัง**
    - ผลที่คาดว่าจะได้: ต่างกันไม่เกิน 0.001 มม.

## จ. เก็บหลักฐาน

13. ภาพหน้าจอ: กดปุ่ม **View Orientation → Isometric** ให้เห็นระนาบ 3 ระนาบกับวงกลมพร้อมตัวเลข
    แล้ว **Windows + Shift + S** (หรือ **File → Save As → JPEG**) — เก็บอีกภาพในมุม **Top** ก็ได้
14. **File → Save As** → `taper_check.SLDPRT` ในโฟลเดอร์ `Desktop\Project\SolidWorks_check\`
15. ทำ ข.–จ. ซ้ำกับ `test 2 shpere.STEP` → บันทึก `sphere_check.SLDPRT`
16. จดเวอร์ชัน SolidWorks (**Help → About SOLIDWORKS**) สำหรับเอกสารอ้างอิง [13]
