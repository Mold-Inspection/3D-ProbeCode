## 1. Work Zero กับ Machine Zero (≈ 1 ชม.)

### 1.1 คำตอบสั้น

| | Machine Zero (MPos = 0,0,0) | Work Zero (G54, WPos = 0,0,0) |
|---|---|---|
| คืออะไร | จุดอ้างอิงของตัวเครื่องเอง | จุดอ้างอิงของชิ้นงาน — ที่ CAD 0,0,0 |
| ตั้งยังไง | **Homing** (`$H`) ชนลิมิตสวิตช์ทุกแกน → GRBL ตั้ง MPos ตามตำแหน่งนั้น | `G10 L20 P1 X0 Y0 Z0` ที่ตำแหน่งปัจจุบัน — ปุ่ม Set Zero ของ OpenBuilds / Find centre ของโปรแกรม |
| ความสัมพันธ์ | — | WPos = MPos − WCO (WCO = ค่า offset ของ G54 ที่ GRBL เก็บใน EEPROM) |
| เครื่องเรา | **`$22 = 0` (ไม่มี homing)** → MPos = 0 ที่ตำแหน่งหัวตอนเปิดเครื่อง/รีเซ็ต — ไม่ใช่จุดคงที่ทางกายภาพ | X0 Y0 = ศูนย์ชิ้นงานจาก Find centre, Z0 = ผิวบน (ตั้งด้วยตา) |

### 1.2 ผลต่องานเรา

- การวัดใช้ **Work Zero อย่างเดียว** — log มีทั้ง WPos และ WCO จึงย้อนเป็นพิกัดเครื่องได้ (ใช้ในรายงาน 4/11, 5/11)

  (X0 Y0 หาใหม่ด้วย Find centre ได้ แต่ Z0 ต้องตั้งใหม่ทุกครั้ง)

## 5. คำถาม: "สิ่งสำคัญที่วัดคือ Repeatability ส่วนความแม่นยำขึ้นกับการวาง environment และการตั้ง Z0 ใช่ไหม"

**ใช่บางส่วน แต่ตัวที่ใหญ่ที่สุดไม่ใช่ Z0**

- **Repeatability คือคุณสมบัติของระบบ** (เครื่อง + โพรบ + โปรแกรม) และเราวัดได้แล้ว: r ≈ 0.06 มม. (แตะตรวจ) / 0.07–0.09 มม. (รวม Find centre)
  ความซ้ำเป็นขีดจำกัดล่าง — ความแม่นยำจะดีกว่าความซ้ำไม่ได้
- **ความแม่นยำ = ความซ้ำ + ความผิดคงที่ (bias)** และ bias ที่วัดได้มาจาก 3 กลุ่ม

  | กลุ่ม | ขนาดที่พบ | ขึ้นกับ |
  |---|---|---|
  | **การคาลิเบรตหัวโพรบ** (Effective Tip วัดจากผนังนอก แต่ใช้กับผนังในรู) | ≈ 0.25 มม. ตามรัศมี — **ใหญ่สุด** เกิดเท่ากันทั้ง sphere และ taper | โปรแกรม/วิธีคาลิเบรต — แก้ได้ด้วยวงแหวนอ้างอิง |
  | **การตั้ง Z0** | ≈ 0 ถึง +0.2 มม. (edge-find); ผลต่อรู = dz × sin(มุมผนัง) | ผู้ใช้/environment |
  | **การวางและยึดชิ้นงาน** | เอียง ≈ 0.6°, ศูนย์ลอย 28 µm, เลื่อน 0.03–0.08 มม. | environment |

- ข้อสรุปสำหรับ paper: ความแม่นยำขึ้นกับ **การคาลิเบรต** (หัวโพรบ, Z0) และ **environment** (การยึดชิ้นงาน, ความแข็งแรงของที่ยึดโพรบ)
  — ส่วนนี้ลดได้ด้วยขั้นตอนที่ถูกต้อง ส่วนความซ้ำเป็นตัวบอกว่าระบบนี้ทำได้ดีแค่ไหนเมื่อคาลิเบรตแล้ว
- ยังขาดเพื่อยืนยันความแม่นยำจริง: วัดชิ้นอ้างอิงที่รู้ขนาด (วงแหวน/gauge pin) — ต้องใช้เครื่อง จัดเป็นงานวันถัดไป
